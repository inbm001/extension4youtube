# Extension for YouTube

흩어져 있는 Chrome 유튜브 북마크를 태그와 시청 상태로 찾는 확장 프로그램의 화면 시안입니다.

**다른 컴퓨터에서 이어서 작업할 때는 [인수인계 문서](HANDOFF.md)를 먼저 읽으세요.** 요구사항, 완료 범위, 미검증 항목, 다음 작업 순서와 사무실 실행 방법을 정리했습니다.

## 현재 결과

- 실제 유튜브 북마크에서 중복 영상을 제외한 1,387개 중 무작위 10개를 추출했습니다.
- Gemini 웹으로 10개 영상의 태그와 선정 근거를 받아 저장했습니다.
- `preview.html`에 표본 10개를 사용한 인터랙티브 화면 시안을 만들었습니다.
- 기본 화면은 **시청중 / 시청완료 / 두고볼 것**, 태그 검색 후에는 영상 목록을 표시하도록 작성했습니다.
- `piano → 피아노`, `에이블톤 → Ableton Live`처럼 검색 별칭을 포함했습니다.

현재는 화면 검토 단계입니다. 확장 프로그램 설치 패키지, 전체 북마크 태깅, 시청 기록 연동은 아직 구현하지 않았습니다. 시안의 시청 상태는 예시이고 변경 내용은 새로고침하면 초기화됩니다. 브라우저에서의 동작 검증은 아직 완료하지 않았습니다.

## 화면 열기

`preview.html`을 브라우저에서 직접 열거나, 이 폴더에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8765/preview.html>을 엽니다. 썸네일 표시에는 인터넷 연결이 필요합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `preview.html` | 기본 보관함과 태그 검색 화면 시안 |
| `tag-sample-10.json` | 무작위 표본의 제목·URL 및 Gemini 요청문 |
| `gemini-tag-results.json` | Gemini가 생성한 태그·선정 근거 |
| `gemini-tag-results.md` | 읽기 쉬운 태그 결과 표 |
| `HANDOFF.md` | 사무실 작업 인수인계와 검증 체크리스트 |

Gemini가 표시한 영상·자막 확인 여부는 자기보고이며 독립 검증하지 않았습니다. 원본 응답에는 표 뒤에 붙은 영상 카드 행도 포함됩니다. 개인정보가 포함된 원본 화면 캡처는 Git에서 제외했습니다.

## 합의한 방향

- Chrome에 저장한 모든 유튜브 북마크를 태깅해 확장 프로그램에서 보여줍니다.
- 검색 전에는 시청 상태별 영상을 기본으로 표시하고, 태그 검색 후에는 결과를 목록으로 표시합니다.
- 비슷하거나 겹치는 태그를 허용하고, 한글·영문·다른 표기의 검색 누락을 별칭으로 줄입니다.
- 브라우저의 ‘Gemini에게 물어보기’ 수준을 태그 품질의 목표로 삼습니다. 현재 시험은 Gemini 웹에서 진행했습니다.
- 자동 태그 추론을 위한 Jev AI 연동은 이후 단계로 둡니다. Chrome Prompt API 사용은 확정하지 않았습니다.
- 전체 구현 전에 화면을 검토합니다.

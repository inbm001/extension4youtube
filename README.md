# Extension for YouTube

## 로컬 검사 전체 실행

`node scripts/check-local.cjs`로 검색·별칭·태그 편집·분류·설명 근거·북마크 계획·시청 상태의 개별 검사를 실행합니다.
하나라도 실패하면 종료 코드가 1이며 결과와 오류는 `.logs/local-checks.json`에 저장합니다.
검사는 로컬 표본 파일이 필요합니다. 새 체크아웃에 개인 `.logs/` 자료가 없으면 해당 검사 실패를 표시합니다.
Chrome 북마크 쓰기·실제 플레이어 연결·브라우저 UI 승인이나 모델 정확도를 검증하는 명령은 아닙니다.
현재 package.json이 없어 pnpm test와 pnpm harness:check 대신 이 명령을 사용합니다.

## 북마크 저장 형식 검증

`node scripts/check-bookmark-format.cjs`로 태그·별칭·시청 상태·재생 위치의 URL 저장과 복원을 확인합니다.
검토한 형식과 남은 제약은 [BOOKMARK-FORMAT.md](BOOKMARK-FORMAT.md)에 있습니다.
이 검사는 Chrome 북마크를 읽거나 수정하지 않습니다.

## 커리큘럼 편집 프로토타입

할 일 서버를 실행한 뒤 <http://127.0.0.1:8770/curriculum>에서 엽니다.
`prototypes/curriculum-editor.html`은 영상 검색·단계 추가·순서 변경·연습 및 완료 기준 작성·미리보기를 시험합니다.
초안은 현재 브라우저의 로컬 저장소에 자동 저장하고 JSON 파일로 내려받을 수 있습니다.
YouTube 재생목록 생성·수정이나 공개·공유는 아직 연결하지 않았습니다. 미리보기의 영상은 원래 YouTube 페이지로 연결합니다.
현재 동작 시험용 초안은 확정된 학습 커리큘럼이 아닙니다.

## 검색 프로토타입 재생성·검증

영상별 `태그 편집`에서 자동 태그를 숨기거나 복원하고 사용자 태그를 추가·삭제할 수 있습니다.
편집 내용은 현재 브라우저에 자동 저장합니다. Gemini 원본 자료와 Chrome 북마크는 수정하지 않습니다.
알려진 한영 별칭은 사용자 태그를 처음 추가할 때 로컬 사전에서 저장합니다. 모르는 태그의 번역은 만들지 않습니다.
`node scripts/check-tag-drafts.cjs`로 원본 태그 갱신 후에도 사용자 편집이 유지되는지와 별칭 재사용을 검사합니다.

`node scripts/build-search-prototype.cjs`로 120개 표본 검색 시안을 갱신합니다.
입력 자료 `.logs/tag-batch-120/merged.json`은 로컬에만 있습니다. 제목 기반 Gemini 원본과 확인 범위를 유지합니다.
`node scripts/check-search.cjs`로 한영 별칭·제목 검색과 대분류 동작을 확인합니다.
분류·별칭 사전은 초기 검증용이며 Jev와 자동 번역 파이프라인은 아직 연결하지 않았습니다.

할 일 표의 스타일·화면 코드는 `tasks.css`, `tasks-ui.js`입니다.
이를 고치면 `node scripts/build-task-board.cjs`로 `tasks.html`을 다시 만듭니다.

## 로컬 할 일 목록

`node scripts/tasks-server.cjs`로 실행하고 <http://127.0.0.1:8770/>을 엽니다.
포트 `8770`은 작업 관리용이며 검색 실험 포트 `8765`와 분리합니다.
실행 PID와 포트는 `.logs/tasks-server.json`에 기록합니다.

작업 자료의 원본은 `tasks.json`입니다. 상태·완료 기준·미결정 사항을 수정하면 화면이 5초마다 반영합니다.
화면은 조회용이며 상태 필터, 업무 검색, 상세 펼치기를 제공합니다.
진행 논의는 `T04` 같은 작업 번호로 연결합니다. 날짜 일정은 아직 정하지 않았습니다.
119개 태그는 Gemini 제목 기반 추출 결과이며 영상 내용 분석 완료를 뜻하지 않습니다.

흩어져 있는 Chrome 유튜브 북마크를 태그와 시청 상태로 찾는 확장 프로그램의 화면 시안입니다.

**다른 컴퓨터에서 이어서 작업할 때는 [인수인계 문서](HANDOFF.md)를 먼저 읽으세요.** 요구사항, 완료 범위, 미검증 항목, 다음 작업 순서와 사무실 실행 방법을 정리했습니다.

## 현재 결과

아래 결과는 기존 시안의 구현 상태입니다. 구현할 주요 기능은 다음 절의 요구사항을 따릅니다.

- 실제 유튜브 북마크에서 중복 영상을 제외한 1,387개 중 무작위 10개를 추출했습니다.
- Gemini 웹으로 10개 영상의 태그와 선정 근거를 받아 저장했습니다.
- `preview.html`에 표본 10개를 사용한 인터랙티브 화면 시안을 만들었습니다.
- 기본 화면은 **시청중 / 시청완료 / 두고볼 것**, 태그 검색 후에는 영상 목록을 표시하도록 작성했습니다.
- `piano → 피아노`, `에이블톤 → Ableton Live`처럼 검색 별칭을 포함했습니다.

현재는 화면 검토 단계입니다. 확장 프로그램 설치 패키지, 전체 북마크 태깅, 시청 기록 연동은 아직 구현하지 않았습니다. 시안의 시청 상태는 예시이고 변경 내용은 새로고침하면 초기화됩니다. 브라우저에서의 동작 검증은 아직 완료하지 않았습니다.

## 주요 기능 요구사항

2026-10-23 사용자 확인. 아래 요구사항이 기존 시안 및 이전 인수인계의 조회·저장 방식 설명보다 우선합니다. 아직 구현하지 않았습니다.

1. **시청 상태를 북마크로 저장합니다.** 사용자의 시청중·완료 상태 정보를 영상 URL 뒤에 부가 정보로 붙여, 지정한 Chrome 북마크 폴더에 저장합니다. 앱 서버에 개인 시청 기록을 저장하지 않습니다. 사용자는 유튜브 정책 우려를 이 제약의 이유로 설명했으며, 정책 위반 여부에 관한 독립 검토는 아직 하지 않았습니다.
2. **조회 페이지에 시청중·완료·다시보기를 표시합니다.** 다시보기는 상시 참고할 강의·매뉴얼을 사용자가 체크박스로 지정하는 기능입니다. 시청중·완료와 독립된 사용자 표시이며, 앞서 논의한 사용자 태그 성격을 유지합니다. 검색하면 조건에 맞는 영상을 표시합니다.
3. **특정 재생 위치 마킹은 보류합니다.** 기획 검토 후 채택 여부와 동작을 결정합니다. 상태 정보를 URL에 저장한다는 요구를 재생 위치 자동 저장 요구로 확대하지 않습니다.

지정 북마크 폴더명, URL 부가 정보 형식, 시청중·완료 판정 및 저장 시점은 설계 단계에서 결정합니다. 기존 북마크의 이동·삭제는 이 요구사항으로 허용된 것으로 간주하지 않습니다.

검색은 정확한 제목보다 사용자가 기억하는 단서로 다시 찾는 흐름을 우선합니다. 입력 중 후보 태그를 추천하고, 제목·폴더명·내용 태그·사용자 태그·별칭을 활용하는 방향입니다. 태그 포함관계 그래프는 첫 구현의 필수 조건으로 두지 않습니다.

### 합의한 등록·시청·조회 동작

- 영상 제목 옆의 태그 버튼을 누르면 추천 태그가 생성되고, 사용자가 삭제·추가할 수 있습니다.
- 태그 생성이 완료되어야 영상을 등록합니다. 단순 재생이나 생성 실패만으로 등록하지 않습니다. 별도 저장 버튼 없이 등록·태그 편집을 저장하는 방향입니다.
- 등록된 영상은 시청중으로 관리합니다. 재생 위치가 전체 길이의 95%에 도달하면 자동 완료하는 편의 기준을 사용합니다. 실제로 서로 다른 구간을 95% 시청했다는 보장은 아닙니다.
- 태그 버튼 옆에 시청완료 버튼과 보관 체크박스를 둡니다. 시청률과 관계없이 직접 완료하거나, 완료를 시청중으로 되돌릴 수 있습니다. 조회 목록에서도 상태를 바꿀 수 있습니다.
- 기존 다시보기 표시는 보관으로 명칭을 맞춥니다. 악보·TAB·강의·매뉴얼처럼 반복 참고하는 영상은 완료되어도 별도 보관 메뉴에 계속 표시합니다.
- 확장 아이콘을 누르면 현재 페이지를 덮는 조회 화면을 열고 검색창에 바로 입력할 수 있게 합니다. 새 탭이나 사이드패널로 전환하는 방식은 채택하지 않았습니다.
- 조회 화면은 Esc 또는 닫기 버튼으로 닫습니다. 열 때 재생 중인 영상은 일시정지하고, 닫을 때 조회 화면이 일시정지한 동일 영상만 이어 재생합니다. 원래 멈춰 있던 영상은 그대로 둡니다.

위 내용은 합의한 목표 동작이며 현재 HTML 시안의 구현 완료를 의미하지 않습니다.

## 화면 열기

`preview.html`을 브라우저에서 직접 열거나, 이 폴더에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8765/preview.html>을 엽니다. 썸네일 표시에는 인터넷 연결이 필요합니다.

## 합의한 방향

- Chrome에 저장한 모든 유튜브 북마크를 태깅해 확장 프로그램에서 보여줍니다.
- 검색 전에는 시청 상태별 영상을 기본으로 표시하고, 태그 검색 후에는 결과를 목록으로 표시합니다.
- 비슷하거나 겹치는 태그를 허용하고, 한글·영문·다른 표기의 검색 누락을 별칭으로 줄입니다.
- 브라우저의 ‘Gemini에게 물어보기’ 수준을 태그 품질의 목표로 삼습니다. 현재 시험은 Gemini 웹에서 진행했습니다.
- 자동 태그 추론을 위한 Jev AI 연동은 이후 단계로 둡니다. Chrome Prompt API 사용은 확정하지 않았습니다.
- 전체 구현 전에 화면을 검토합니다.

확장 자산 CSP 시험은 node scripts/build-extension-assets.cjs 후 node scripts/extension-preview-server.cjs로 실행합니다. 포트는 127.0.0.1:8771이며 PID 기록은 .logs/extension-preview-server.json입니다. 개인 표본 포함 로컬 시험이며 설치된 확장 환경을 대체하지 않습니다.
